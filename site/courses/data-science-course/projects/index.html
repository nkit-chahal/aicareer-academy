Industry-Grade Capstone Projects

Every project mirrors a real production problem from a real company vertical. You ship code that could go live — not a Titanic CSV with 90% accuracy.

Enterprise AI

RAG Chatbot for Enterprise Knowledge Base

Build a production-grade RAG chatbot that ingests company documents — PDFs, Confluence pages, Notion exports — chunks and embeds them into a vector store, retrieves relevant context, and generates accurate answers with source citations. Handle multi-turn conversations, hallucination guardrails, and a simple eval pipeline to measure answer quality.

LangChain OpenAI API ChromaDB FastAPI Streamlit

Deployed chatbot with source citations, eval metrics, and a live Streamlit demo — portfolio ready.

GeoAI / Defence

Satellite Imagery Object Detection

Detect and classify objects — buildings, vehicles, ships, aircraft — from satellite imagery using deep learning. Fine-tune a pre-trained detection model on geospatial data, handle large tile images with a sliding window approach, and output geo-referenced bounding boxes that can be visualized on a map.

YOLOv8 PyTorch Rasterio GeoPandas OpenCV

Object detection pipeline on satellite tiles with map visualization — a rare, high-impact portfolio piece.

AI Agents

Personal AI Assistant Agent

Build an autonomous AI assistant that manages your calendar, drafts emails, summarizes meeting notes, and executes multi-step tasks using tool calling. Wire up function calling with real APIs — Google Calendar, Gmail, Notion — and implement memory so the agent remembers context across sessions.

LLM Agents Function Calling LangGraph OAuth2 Python

Multi-tool AI agent with persistent memory — demonstrates agentic AI skills interviewers are hiring for.

Creative AI

Text-to-Image Generation Platform

Build an image generation app using Stable Diffusion and diffusion model APIs. Implement prompt engineering techniques, negative prompts, style transfer, and image-to-image workflows. Add a web UI where users type a prompt and get styled outputs — with safety filters and cost controls for API usage.

Stable Diffusion Diffusers DALL·E API Gradio PyTorch

Working image generation app with prompt controls and style presets — visual, shareable, impressive.

GenAI Project

AI Travel Agent — Flights, Hotels & Itineraries

Build an AI-powered travel planner that takes a natural language trip request — "5 days in Bali, budget ₹80k, adventure + relaxation" — and autonomously searches flights, compares hotels, and generates a day-by-day itinerary. Uses tool calling to hit real travel APIs and returns structured, bookable recommendations.

LLM Agents Tool Calling Travel APIs FastAPI Streamlit

End-to-end AI agent that plans trips with real data — a demo that wows in any interview.

HR Tech

AI Resume Screening & Ranking System

Build an intelligent resume screener that parses PDFs, extracts skills and experience using NLP, matches candidates against a job description using semantic similarity, and ranks them with explainable scores. Handle edge cases — career gaps, non-standard formats, multilingual CVs — and output a recruiter-ready shortlist.

Sentence Transformers spaCy LLM APIs Pandas Streamlit

Automated screening pipeline with ranking dashboard — solves a real hiring bottleneck.

FinTech

Real-Time Transaction Fraud Detection

Build a fraud detection system that scores transactions in real-time. Engineer behavioral features from transaction sequences, handle extreme class imbalance, train an ensemble model, and serve predictions via API with sub-100ms latency. Add an LLM layer that generates human-readable fraud explanations for the ops team.

XGBoost Feature Engineering FastAPI LLM Explainer Docker

Real-time scoring API with explainability — classic ML + GenAI in one production system.
