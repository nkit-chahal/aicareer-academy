Data Analyst

Turn messy tables into decisions leaders can trust.

5–6 months

Best for Beginners, business grads, and anyone who wants a first role in data.

0 · Python — Every path starts here. Syntax, data, and how to think in code — then you specialize.

  1. 01

    Python + spreadsheets

    Pandas, Excel, and clean data habits. You should be able to load a CSV and answer a business question.

  2. 02

    SQL

    Joins, aggregations, window functions. Most analyst interviews live here.

  3. 03

    BI dashboards

    Power BI or similar: KPIs, filters, and a story a manager can scan in 30 seconds.

  4. 04

    Stats for business

    Averages, trends, A/B intuition — enough to not get fooled by a chart.

  5. 05

    AI-assisted analysis

    Use AI to speed cleaning and commentary, then ship a portfolio dashboard.

ML Engineer

Take models out of notebooks and into production.

5–7 months

Best for Python developers and data scientists who want systems, not just accuracy.

0 · Python — Every path starts here. Syntax, data, and how to think in code — then you specialize.

  1. 01

    Python engineering

    Packages, tests, typing. Treat model code like product code.

  2. 02

    Classical ML depth

    Feature pipelines, training loops, evaluation you can defend in review.

  3. 03

    Serving

    APIs, batch jobs, latency vs throughput. A model that nobody can call is a hobby.

  4. 04

    MLOps layer

    Version data and models, CI for training, monitoring drift.

  5. 05

    Ship a system

    One project from dataset to trained artifact to endpoint with logs.

LLM Engineer

Embeddings, RAG, evals, and inference that actually scales.

2–5 months

Best for Developers who want to specialize in large language models.

0 · Python — Every path starts here. Syntax, data, and how to think in code — then you specialize.

  1. 01

    Python + APIs

    Call models cleanly. Handle tokens, retries, and cost.

  2. 02

    Embeddings & retrieval

    Chunking, vector search, why RAG fails in production.

  3. 03

    Fine-tuning & PEFT

    When to fine-tune vs prompt vs retrieve. Measure, don’t guess.

  4. 04

    Evals

    Golden sets, hallucination checks, latency/cost tradeoffs.

  5. 05

    Serve

    Batching, caching, safety filters. Optional: LLMOps course next.

MLOps Engineer

Pipelines, containers, and reliability for ML and AI services.

4–6 months

Best for Backend or infra people who want to own AI in production.

0 · Python — Every path starts here. Syntax, data, and how to think in code — then you specialize.

  1. 01

    Python + Linux basics

    Scripts, env management, enough Python to debug a training job.

  2. 02

    Containers

    Docker images that train and serve. Repeatable on another machine.

  3. 03

    CI/CD for models

    Tests on data contracts, gated deploys, rollback when a model is worse.

  4. 04

    Orchestration

    Kubernetes or equivalent: health checks, scaling, secrets.

  5. 05

    Observe & govern

    Metrics, cost, drift. Then LLMOps if you are running GenAI.

Data Scientist

Python, models, and experiments — not just dashboards.

6–10 months

Best for Analysts who want modeling, or engineers moving into applied ML.

0 · Python — Every path starts here. Syntax, data, and how to think in code — then you specialize.

  1. 01

    Python for science

    NumPy, Pandas, visualization. Reproducible notebooks, not one-off scripts.

  2. 02

    Statistics & EDA

    Distributions, leakage, bias. Learn to distrust a pretty plot.

  3. 03

    Core machine learning

    Regression, classification, clustering, evaluation metrics that match the job.

  4. 04

    Deep learning basics

    Enough neural nets to use modern tools without cargo-culting.

  5. 05

    LLMs in the stack

    RAG and model APIs as products, plus a portfolio that shows end-to-end thinking.

Agentic AI

Agents that plan, use tools, and finish multi-step work.

3–5 months

Best for Builders who already know Python and want autonomous workflows.

0 · Python — Every path starts here. Syntax, data, and how to think in code — then you specialize.

  1. 01

    Python + LLM apps

    Solid API usage and structured outputs before you add loops.

  2. 02

    Tool use

    Functions, APIs, files. An agent without tools is a chatbot with extra steps.

  3. 03

    Planning & memory

    State, retries, human-in-the-loop. Stop infinite loops.

  4. 04

    Multi-agent patterns

    LangGraph-style graphs, roles, handoffs — keep it small and testable.

  5. 05

    Evaluate agents

    Task success rate, cost per run, traces. Then ship one real workflow.

AI Developer

Ship AI into products: RAG chat, copilots, internal tools.

3–5 months

Best for Software engineers adding GenAI to apps they already build.

0 · Python — Every path starts here. Syntax, data, and how to think in code — then you specialize.

  1. 01

    Python in your stack

    Or call models from the language you ship — the path still starts with clear APIs.

  2. 02

    Prompt + product UX

    Streaming, citations, empty states. Users don’t care about your prompt file.

  3. 03

    RAG in the app

    Index company docs, permissions, freshness. Ground answers.

  4. 04

    Agents when needed

    Workflows, not demos. Guardrails and logging.

  5. 05

    Production

    Auth, rate limits, evals in CI. Optional: full Gen AI specialization.
